A make.fun entry for **The Word You'd Delete From the Dictionary**: one word
the entrant would erase from the dictionary forever. This entry picks
**irregardless** — a double negative that bluffed its way into the dictionary
even though "regardless" already does the whole job. Delete it and nothing is
lost, which is exactly the joke.

## Run

```sh
node main.ts
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
